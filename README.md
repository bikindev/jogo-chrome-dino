# Jogo Chrome Dino

Jogo inspirado no Dino do Chrome, desenvolvido com HTML, CSS e JavaScript. O objetivo é fazer o dinossauro pular os cactos e evitar colisões.

## Como executar

Abra o arquivo `index.html` em um navegador.

## Controles

- **Espaço:** iniciar o jogo
- **Espaço durante a partida:** fazer o dinossauro pular
- **Espaço após o game over:** reiniciar o jogo

## Estrutura do projeto

- `index.html`: estrutura da página e elementos do jogo
- `page/style.css`: estilos, posições e animações
- `page/script.js`: estados do jogo, controles e colisões
- `images/`: imagens do dinossauro, dos cactos e do chão

## Tecnologias

- HTML5
- CSS3
- JavaScript
